# Story 8.4: 价格与资料模块枚举接入

**Status:** review
**Story Key:** 8-4-价格与资料模块枚举接入
**Epic:** 8 - 数据导入与系统配置
**Date:** 2026-04-23

---

## User Story

As a 财务部用户 / 产品部用户,
I want 在价格管理与产品资料模块中直接使用系统统一维护的国家/地区、币种、资料类型枚举,
So that 关键字段提交标准编码或稳定枚举键，不再依赖页面硬编码或自由文本。

---

## Acceptance Criteria

**Given** `country_region` 与 `currency` 枚举组已配置  
**When** 财务部用户进入价格新增/编辑页  
**Then** 国家/地区与币种字段以下拉方式展示统一枚举选项  
**And** 默认区域仍为 `GLOBAL`，提交值为标准编码（如 `CN`、`US`、`GLOBAL`）

**Given** `document_type` 与 `country_region` 枚举组已配置  
**When** 产品部用户进入资料新增/编辑页  
**Then** 资料类型字段使用统一枚举选项  
**And** 适用国家/地区字段以下拉多选方式展示并提交标准编码

**Given** 管理员在系统配置页调整国家/地区、币种或资料类型枚举值  
**When** 财务部或产品部重新进入价格/资料页面  
**Then** 表单选项与筛选项立即反映最新启用枚举  
**And** 禁用枚举不再出现在普通业务选择中

---

## Scope

### In Scope

- 价格模块接入 `country_region`、`currency` 枚举读取与表单选择
- 资料模块接入 `document_type`、`country_region` 枚举读取与表单选择
- 前端通用枚举读取封装（仅限本 Story 所需的最小复用）
- 价格 / 资料模块相关前端测试与必要的后端契约收口
- 保持现有价格审批流、资料归属模型、KeepAlive 路由与缓存模式不变

### Out of Scope

- 证书、FAQ、SPU、SKU 模块的枚举接入
- 新增新的枚举组或扩展 8.3 枚举管理后台能力
- 全仓统一枚举 label 解析层重构
- 价格审批规则、资料上传能力或归属模型调整

## Dev Notes

### 关键实现约束

1. 8.4 只做价格与资料模块，不提前展开到 8.5 / 8.6
2. 价格模块优先以 `country_code`、`currency` 稳定提交，尽量避免继续依赖手输 `country_name`
3. 资料模块的 `applicable_countries` 前端默认值仍为 `[]`，提交前必须兜底数组
4. 前端继续沿用 KeepAlive、TanStack Query、现有缓存失效模式，不做通用大重构
5. 列表页保持紧凑内容区，不额外加页面标题；表单页仍遵循当前三列表单节奏
6. 枚举读取仅消费 8.3 已完成的 `/api/v1/enums`、`/api/v1/enums/groups` 契约
