## 关键实现规范

### 1. `app/db/base.py` — SQLAlchemy BaseModel Mixin（必须精确实现）

```python
from datetime import datetime
from sqlalchemy import DateTime, Integer
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy.sql import func

class Base(DeclarativeBase):
    pass

class BaseModel(Base):
    """所有业务实体的基类 Mixin。所有 SQLAlchemy Model 必须继承此类。"""
    __abstract__ = True

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), nullable=False
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), onupdate=func.now(), nullable=False
    )
    deleted_at: Mapped[datetime | None] = mapped_column(
        DateTime(timezone=True), nullable=True, default=None
    )
```

**强制规则：** 所有后续业务模型（users、product_categories、spus、skus 等）**必须**继承 `BaseModel`，不得继承 `Base`。

### 2. `app/db/session.py` — 异步数据库会话

```python
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine
from app.core.config import settings

# URL 格式：mysql+aiomysql://user:pass@host:port/dbname
engine = create_async_engine(settings.DATABASE_URL, echo=settings.DEBUG)
AsyncSessionLocal = async_sessionmaker(engine, expire_on_commit=False)

async def get_db() -> AsyncGenerator[AsyncSession, None]:
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

### 3. `app/schemas/common.py` — 统一响应 Schema

```python
from typing import Generic, TypeVar
from pydantic import BaseModel

T = TypeVar("T")

class PaginatedResponse(BaseModel, Generic[T]):
    items: list[T]
    total: int
    page: int
    page_size: int

class ErrorDetail(BaseModel):
    field: str | None = None
    msg: str

class ErrorResponse(BaseModel):
    code: str       # 大写下划线: VALIDATION_ERROR, NOT_FOUND, FORBIDDEN, BUSINESS_ERROR
    message: str    # 中文，面向用户
    details: list[ErrorDetail] | None = None
```

### 4. `app/core/exceptions.py` — 自定义异常与全局处理器

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from app.schemas.common import ErrorResponse

class BusinessError(Exception):
    def __init__(self, message: str, code: str = "BUSINESS_ERROR", status_code: int = 400):
        self.message = message
        self.code = code
        self.status_code = status_code

def register_exception_handlers(app: FastAPI) -> None:
    @app.exception_handler(BusinessError)
    async def business_error_handler(request: Request, exc: BusinessError):
        return JSONResponse(
            status_code=exc.status_code,
            content=ErrorResponse(code=exc.code, message=exc.message).model_dump()
        )

    @app.exception_handler(Exception)
    async def generic_error_handler(request: Request, exc: Exception):
        return JSONResponse(
            status_code=500,
            content=ErrorResponse(code="INTERNAL_ERROR", message="服务器内部错误").model_dump()
        )
```

**使用规则：**
- Router 层**不做** try/catch
- Service 层抛出 `BusinessError`，框架自动处理
- 所有业务校验失败（唯一性冲突、关联存在等）统一抛 `BusinessError`

### 7. `app/repositories/base_repository.py` — 基础 Repository

```python
from typing import Generic, Type, TypeVar
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.db.base import BaseModel

T = TypeVar("T", bound=BaseModel)

class BaseRepository(Generic[T]):
    def __init__(self, model: Type[T], db: AsyncSession):
        self.model = model
        self.db = db

    async def get_by_id(self, id: int) -> T | None:
        result = await self.db.execute(
            select(self.model).where(
                self.model.id == id,
                self.model.deleted_at.is_(None)  # 软删除过滤
            )
        )
        return result.scalar_one_or_none()

    async def soft_delete(self, entity: T) -> None:
        from datetime import datetime, timezone
        entity.deleted_at = datetime.now(timezone.utc)
        self.db.add(entity)
```

**软删除强制规则：** 所有查询必须过滤 `deleted_at IS NULL`。通过 BaseRepository 方法统一处理，禁止在子类中遗漏此过滤。

## 架构遵守规则（AI Agent 强制执行）

以下规则贯穿整个项目，本 Story 建立的基础设施必须支撑这些规则：

1. **新增后端业务模块必须创建 model / schema / router / service / repository 五个文件**（后续 Story 遵守）
2. **所有 SQLAlchemy Model 必须继承 `BaseModel`**（含 id / created_at / updated_at / deleted_at）
3. **所有删除操作必须软删除**，禁止物理删除核心业务数据
4. **所有 Router 必须通过 `Depends()` 注入权限检查**（Story 1.3 建立后强制）
5. **前端所有 API 调用必须通过 TanStack Query**，禁止组件内直接 `axios.get()`
6. **前端组件禁止直接修改服务端数据状态**，必须通过 `mutation.mutate()` + Query invalidation
7. **所有 API 响应必须符合统一格式**（`PaginatedResponse` / `ErrorResponse`）

## 常见陷阱预防

| 陷阱 | 预防措施 |
|------|---------|
| SQLAlchemy 2.x 与 1.x API 差异 | 使用 `Mapped[T]` 类型注解风格，不用旧式 `Column(...)` |
| TanStack Query v5 API 变化 | v5 废弃了 `onSuccess`/`onError` 回调，使用 `.then()` 链式或 `useEffect` 处理副作用 |
| AntD 5.x + Tailwind CSS 冲突 | `tailwind.config.ts` 必须设置 `important: '#root'` |
| MySQL async 驱动 | DATABASE_URL 格式用 `mysql+aiomysql://`，不是 `mysql://` |
| Alembic async 迁移 | `env.py` 需要使用 `asyncio.run()` 包装 async 迁移 |
| CORS + Cookie 认证 | `withCredentials: true`（Axios） + `allow_credentials=True`（FastAPI CORS） 两者必须同时配置 |
| React 19 严格模式 | 开发模式下 effects 执行两次是正常的，不是 bug |
| `deleted_at` 软删除遗漏 | 所有 Repository 查询通过 `BaseRepository.get_by_id()` 或显式加 `where(deleted_at.is_(None))` |
