## 执行摘要

产品管理模块是跨境医疗器械 ERP 系统的主数据中台，为销售订单、采购、仓储、发运、报关全链路提供权威产品数据支撑。核心实体为 SPU（标准产品单元，一对一绑定供应商）和 SKU（规格变体，继承 SPU 信息），以此为中心，向上聚合证书、资料、FAQ、销售价格，向下驱动每一笔业务单据的产品关联。

**目标用户：** 产品部（主数据维护）、商务部（报关信息维护）、财务部（定价维护），以及所有下游模块用户。

**解决的核心问题：** 跨境医疗器械出口场景下，产品数据不一致会导致连锁失控——错误的 HSCODE 影响报关、过期证书漏发客户、价格变更无记录引发对账争议。本模块提供唯一可信的产品数据源，使每个环节都从同一数据集取数，而非各部门分散维护。

### 产品核心价值

- **聚合展示**：SKU 详情页一键呈现所有关联证书、产品资料、FAQ、区域定价，消除跨系统/跨文件夹查找成本
- **合规数据链路**：证书归属模型（通用/SPU/分类）自动关联到 SKU 详情，发运时直接调取输出，不依赖人工归集
- **受控变更**：销售价格变更走审批流，报关 HSCODE 由商务部专属维护，关键数据的修改有据可查
- **数据继承一致性**：SKU 从 SPU 继承供应商、分类、禁止经营国家，减少冗余录入，保证数据关系正确

## 用户旅程

### 旅程一：产品部 — 新增 SKU

**场景：** 产品部同事需要录入一款新型号设备

1. 确认所属分类已存在，否则先在分类管理中维护三级分类树
2. 确认所属 SPU 已存在，否则先新增 SPU（填写基础信息、采购信息、开票信息）
3. 在 SKU 列表页点击"新增"
4. 选择所属 SPU，系统自动继承分类、供应商、禁止经营国家
5. 填写 SKU 基础信息、产品属性、包装信息、包装明细、上传产品图片
6. 报关信息区域留空，等待商务部维护
7. 保存，SKU 状态默认"上架"
8. 通知商务部补充报关信息

**关键规则约束：** SPU编码/SKU编码唯一性校验；继承字段只读；开票信息至少一条；分类编码创建后不可修改

---

### 旅程二：商务部 — 维护报关信息

**场景：** 商务部收到通知，需要为新 SKU 补充报关信息

1. 在 SKU 列表页按关键词搜索，找到目标 SKU
2. 进入 SKU 编辑页，定位到报关信息分区
3. 填写 HSCODE、监管条件、申报要素、退税税点
4. 勾选"是否已维护报关信息"为"是"
5. 保存

**权限约束：** 报关信息仅商务部可编辑，产品部只读

---

### 旅程三：财务部 — 设置区域价格

**场景：** 财务部为新上架 SKU 设置全球及分区价格

1. 进入销售价格管理列表，搜索 SKU
2. 新增定价记录，选择 SKU 后自动带出产品信息
3. 在区域价格子表中，分别为"全球"和指定国家/地区设置销售价、列表价、币种
4. 提交价格变更，等待审批
5. 审批通过后，价格在 SKU 详情页生效展示

**关键规则：** 同一 SKU 同一国家/地区不可重复；价格生效前审批通过；SKU 详情页展示最新已审批价格

---

### 旅程四：管理员 — 系统上线初始化数据导入

**场景：** 系统上线前，管理员批量迁移历史产品数据

1. 下载系统提供的分类/SPU/SKU 导入模板
2. 按模板格式整理历史数据，填入 Excel
3. 上传 Excel，系统执行格式校验和唯一性检查
4. 查看校验结果：成功条数 / 失败条数 / 失败原因明细
5. 修正失败数据，重新上传
6. 确认导入，历史数据迁移完成

---

### 旅程五：产品部 — 管理产品证书

**场景：** 产品部同事需要为某 SPU 录入 CE 证书，并确保到期前系统可发出预警

1. 进入产品证书管理列表，点击"新增"
2. 填写证书名称、证书编号、证书类型（CE）、发证机构、有效期起始日期和结束日期
3. 选择归属类型：SPU 归属，选择对应 SPU
4. 上传证书文件
5. 保存；证书进入列表，系统根据有效期结束日期自动标记状态（有效/即将过期/已过期）
6. 当有效期结束日期前 30 天（可配置），系统自动将证书状态标记为"即将过期"
7. 在 SKU 详情页验证：该 SPU 下 SKU 的详情页"产品证书"分区已正确展示该证书

**关键规则：** 证书编号全局唯一；有效期起始日期须早于结束日期；已过期证书保留历史记录，不自动删除

---

### 旅程六：产品部 — 维护产品资料与 FAQ

**场景：** 产品部同事需要为一款设备上传规格说明书，并补充该产品的常见问题

1. **维护资料：** 进入产品资料库，点击"新增"
2. 填写资料名称，选择资料类型（规格说明书），上传文件
3. 设置归属类型为"指定 SKU"，选择对应 SKU
4. 保存
5. **维护 FAQ：** 进入 FAQ 管理，点击"新增"
6. 选择对应 SPU，填写问题与答案，保存
7. **验证聚合展示：** 在 SKU 详情页，确认"产品资料"分区已展示新上传的资料，"FAQ"分区已展示新增的问题

**关键规则：** 资料内容和资料文件至少填写一项；归属为"指定 SKU"时 SKU 必填；FAQ 不指定 SPU 则为全局 FAQ

## B2B 企业应用特定需求

### 权限与访问控制（RBAC）

产品管理模块采用基于角色的访问控制，已在权限设计章节（十）完整定义。核心原则：

- 最小权限原则：各角色仅具备完成本职工作所需的最小权限
- 字段级权限：报关信息字段仅商务部可编辑，产品部只读；价格信息财务部可编辑，其他只读
- 数据可见性控制：采购价、销售价按角色控制可见性，避免敏感定价信息泄露

### 集成与数据流

**模块内部集成（当前阶段）：**

| 数据流向 | 说明 |
|----------|------|
| 产品管理 → 销售订单模块 | 提供 SKU 主数据、禁止经营国家、产品状态 |
| 产品管理 → 采购模块 | 提供 SPU 供应商关联、SKU 采购信息 |
| 产品管理 → 仓储模块 | 提供 SKU 基础信息作为库存管理维度 |
| 产品管理 → 发运/报关模块 | 提供 SKU 报关信息（HSCODE）、关联证书 |
| 财务模块 → 产品管理 | 销售价格在 SKU 详情页只读展示（由财务模块维护）|

**外部集成（后续阶段，不在当前范围）：**
- CRM 接口对接（二期）
- 金蝶财务数据推送（三期）

### 技术架构考量

- **单租户架构**：内部系统，无需多租户隔离
- **数据完整性**：产品主数据被多个下游模块依赖，更新操作需防止破坏下游引用（如 SKU 编码不可修改）
- **审批工作流**：价格变更审批为轻量级内置流程，无需引入独立工作流引擎
- **文件存储**：支持产品图片、证书文件、资料文件上传，需规划文件存储方案

## 功能需求

### 产品分类管理

- **FR1**：产品部可创建、编辑三级产品分类，维护层级关系（一级/二级/三级）
- **FR2**：产品部可调整同级分类的显示排序
- **FR3**：系统阻止删除已有 SPU 关联的分类
- **FR4**：分类编码在创建后不可修改

### SPU 管理

- **FR5**：产品部可创建、编辑 SPU，设置基础信息、采购信息及多条开票信息
- **FR6**：每个 SPU 唯一绑定一个供应商；在 SKU 被业务单据引用后，供应商不可变更
- **FR7**：SPU 详情页聚合展示：下属 SKU 列表、关联证书（直属+通用+分类匹配）、关联 FAQ（SPU 级+全局）
- **FR8**：分类选择支持三级联动

### SKU 管理

- **FR9**：产品部可创建、编辑 SKU，选择 SPU 后自动继承分类、供应商、禁止经营国家
- **FR10**：SKU 编码全局唯一，创建后不可修改
- **FR11**：产品部可管理 SKU 产品状态（上架/下架可售/下架不可售/临拓）
- **FR12**：商务部可维护 SKU 报关信息（HSCODE、监管条件、申报要素、退税税点）；产品部只读
- **FR13**：SKU 详情页聚合展示：关联证书、产品资料、FAQ、销售价格
- **FR14**：SKU 支持上传多张产品图片

### 产品资料库管理

- **FR15**：产品部可创建、编辑、删除产品资料，支持富文本内容和多文件附件
- **FR16**：资料归属支持三种模式：通用、指定 SKU（多选）、按分类
- **FR17**：资料可设定适用国家/地区范围

### 产品证书管理

- **FR18**：产品部可创建、编辑、删除产品证书，记录有效期起止日期
- **FR19**：证书归属支持三种模式：通用、SPU 归属（多选）、按分类
- **FR20**：系统在证书有效期结束前 N 天（可配置，默认 30 天）标记"即将过期"
- **FR21**：系统将超过有效期的证书标记"已过期"，到期后保留历史记录

### FAQ 管理

- **FR22**：产品部可创建、编辑、删除 FAQ，支持全局范围和 SPU 级别范围
- **FR23**：FAQ 支持附件上传

### 销售价格管理

- **FR24**：财务部可为 SKU 设置多条区域价格（国家/地区、销售价、列表价、币种）
- **FR25**：同一 SKU 同一国家/地区不允许重复设置价格
- **FR26**：价格变更需提交审批，审批通过前原有价格继续生效
- **FR27**：有审批权限的用户可审批或驳回价格变更申请

### 数据导入

- **FR28**：管理员可下载系统提供的分类/SPU/SKU 标准导入模板
- **FR29**：管理员可通过 Excel 批量导入分类、SPU、SKU 数据
- **FR30**：系统对导入数据进行校验（格式、必填项、唯一性、关联有效性），并展示成功/失败明细
- **FR31**：校验失败后支持修正数据重新上传

### 搜索与筛选

- **FR32**：用户可按一级/二级/三级分类、供应商、产品状态、产品类型筛选 SPU/SKU 列表
- **FR33**：用户可通过关键词对 SPU/SKU/证书/资料进行模糊搜索
- **FR34**：证书列表支持按有效状态（有效/即将过期/已过期）筛选

### 权限与访问控制

- **FR35**：系统按角色（产品部/商务部/财务部/管理员）控制各子模块的读写权限
- **FR36**：系统按角色控制敏感数据可见性（采购价仅产品部/财务部/管理员可见；价格详情仅财务部/管理员可完整编辑）
- **FR37**：管理员可维护系统枚举值配置（单位、产品类型、证书类型、资料类型等）

## 非功能需求

### 性能

- 常规页面加载（列表页、详情页）响应时间：P95 不超过 **2 秒**（20 名并发用户，正常网络环境），核心接口纳入 APM 监控
- SKU 详情页聚合查询（证书+资料+FAQ+价格关联）响应时间：P95 不超过 **3 秒**
- Excel 导入：单次导入 1000 条数据，处理时间不超过 **30 秒**，超过时提供进度反馈
- 系统支持 **20 名**内部用户并发在线正常使用；数据规模基线：SKU 总量 ≥ 10,000 条

### 安全

- 所有用户操作须经身份认证，未登录不可访问任何页面
- 敏感字段（采购价、销售价）按角色权限控制可见性，系统不向无权限用户暴露敏感字段内容
- 数据传输使用 HTTPS 加密
- 关键数据变更（价格修改、产品下架）记录操作日志（操作人、时间、变更前后值）

### 可靠性

- 工作时间（周一至周五 9:00-20:00）系统可用性不低于 **99%**（以月度计划内工作时长内停机 ≤ 1.44 小时为测量依据）
- 允许计划内维护停机（提前通知，非工作时间进行）
- 数据库**每日自动备份**，支持最近 **7 天**内的数据恢复

### 可用性

- 系统界面语言为**中文**，面向内部中文用户使用

## 领域合规要求

本系统为跨境医疗器械贸易 ERP，产品管理模块须满足以下合规数据管理要求：

### 产品证书合规

- **证书类型覆盖**：系统支持 CE、FDA 510(k)、ISO 13485、IEC 检测报告等主流医疗器械出口证书的归类管理
- **证书有效期管控**：通过到期预警机制（提前 N 天，默认 30 天可配置）确保证书在有效期内，防止向客户发运时调取已过期证书
- **证书历史存档**：过期证书保留历史记录，支持医疗器械行业审计追溯要求

### 出口报关合规

- **HSCODE 专属维护权限**：报关 HSCODE 由商务部专属维护，产品部只读，防止误操作影响合规申报
- **申报要素完整性**：系统记录 HSCODE、监管条件、申报要素、退税税点，供发运/报关模块取数使用

### 数据变更审计

- **关键操作日志**：价格修改、产品下架等关键变更记录操作人、时间、变更前后值，满足财务合规和内部审计要求
- **价格变更审批链路**：销售价格变更须经具有 `product:price:approve` 权限的用户审批方可生效

> **适用范围说明：** 本 ERP 系统属于内部业务管理软件，不构成医疗器械软件本身（SaMD），无需申请 FDA 510(k) 软件注册或符合 MDR 软件法规。HIPAA 患者数据保护要求不适用本系统。上述合规要求聚焦于医疗器械出口贸易数据的合规管理。

## 一、模块范围与设计原则

### 子模块范围

| 子模块 | 说明 | 维护方 |
|--------|------|--------|
| 分类管理 | 三级产品分类树 | 产品部 |
| SPU 管理 | 产品型号，绑定唯一供应商 | 产品部 |
| SKU 管理 | SPU 下的规格变体 | 产品部（报关信息由商务部维护） |
| 产品资料库 | 产品相关文档资料 | 产品部 |
| 产品证书管理 | 合规证书与资质 | 产品部 |
| FAQ 管理 | 产品常见问题 | 产品部 |
| 销售价格管理 | SKU 区域定价 | 财务部 |

### 核心设计原则

- **SPU 与供应商一对一**：一个 SPU 只绑定一个供应商，SKU 从 SPU 继承供应商
- **SKU 是规格变体**：同一 SPU 下的 SKU 是不同规格/配置，非不同供应商
- **归属模型统一**：资料、证书共用"通用/SPU/分类/指定SKU"归属机制
- **SKU 详情聚合展示**：查看 SKU 时自动关联展示证书、资料、FAQ、价格

### 3.3 页面与操作

**SPU 列表页：**

**SPU 新增/编辑页：**
- 表单布局分区：基础信息、采购信息、开票信息

- 供应商从供应商主数据中选择

**SPU 详情页：**
- 展示 SPU 全部信息
- 底部展示该 SPU 下的 SKU 列表（SKU编码、SKU中文名称，可点击跳转）
- 关联的证书列表（包含：直接归属该 SPU 的证书 + 通用证书 + 该 SPU 分类匹配的证书）
- 关联的 FAQ 列表（包含：该 SPU 的 FAQ + 全局 FAQ）

**业务规则：**
- SPU编码全局唯一，创建后不可修改
- 供应商一旦绑定，如该 SPU 下已有 SKU 被订单/采购单引用，则供应商不可修改
- 开票信息至少一条

**SKU 列表页：**
- 筛选条件：一级分类、二级分类、三级分类、供应商、产品状态、产品类型、关键词搜索（SKU编码/中文名称/英文名称模糊匹配）
- 列表字段：SKU编码、SKU中文名称、产品型号、SPU编码、供应商、产品状态、创建时间
- 操作：新增、查看详情、编辑
- 支持 Excel 导入（见第九节）

**SKU 新增/编辑页：**
- 表单布局分区：基础信息、产品属性、特殊属性、包装信息、包装明细、报关信息、产品图片
- 选择 SPU 后自动填充继承字段
- 报关信息区域：产品部可见但不可编辑，仅商务部有编辑权限

**SKU 详情页（聚合展示）：**
- 顶部：SKU 全部字段信息
- Tab 或分区展示关联数据：
  - **销售价格表**（只读）：从财务模块关联，按国家/地区展示销售价、列表价、币种
  - **产品证书**：该 SKU 所属 SPU 的证书 + 通用证书 + 分类匹配证书
  - **产品资料**：通用资料 + 指定该 SKU 的资料 + 该 SKU 所属分类的资料
  - **FAQ**：该 SKU 所属 SPU 的 FAQ + 全局 FAQ

**业务规则：**
- SKU编码全局唯一，创建后不可修改
- 必须先选择 SPU，分类和供应商自动继承
- 产品状态默认"上架"
- "下架可售"：不主动推荐，但已有客户仍可下单
- "下架不可售"：完全停售，新订单不可选择该 SKU，不影响已有订单
- "临拓"：临时拓展产品，可正常下单
- 客户质保期从 SPU 继承，但 SKU 级别可覆盖（覆盖后以 SKU 值为准）

- 财务人员提交价格变更后需经审批
- 审批通过后价格生效
- 审批流程（提交/审批通过/驳回）在产品管理模块的价格子模块中实现，由具有 `product:price:approve` 权限的用户执行审批操作

**业务规则：**
- 同一 SKU 同一国家/地区不可重复设置价格
- 价格变更需审批，审批通过前使用原价格
- SKU 详情页展示的价格为最新已审批生效的价格

## 九、数据导入

### 9.1 Excel 导入

系统上线时需支持批量导入历史产品数据。

**支持导入的数据：**

| 导入对象 | 说明 |
|----------|------|
| 分类数据 | 三级分类树 |
| SPU 数据 | 含基础信息、采购信息 |
| SKU 数据 | 含基础信息、产品属性、包装信息、报关信息 |

**导入流程：**
1. 下载导入模板（系统提供标准 Excel 模板）
2. 按模板格式填写数据
3. 上传 Excel 文件
4. 系统校验数据（格式、必填项、唯一性、关联关系）
5. 展示校验结果：成功条数 / 失败条数 / 失败原因明细
6. 确认后执行导入

**校验规则：**
- SPU编码 / SKU编码 唯一性检查
- 关联字段有效性检查（如分类、供应商必须已存在）
- 必填字段非空检查
- 数据格式检查（如质保期必须为正整数）
